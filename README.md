# Network Traffic Analysis Using Machine Learning

# Project Overview
This project focuses on analyzing and classifying network traffic using Machine Learning algorithms. The system processes network traffic data, performs preprocessing, and evaluates multiple machine learning models to determine the most effective approach for traffic classification.

# Technologies Used
* Python
* NumPy
* Pandas
* Scikit-Learn
* TensorFlow
* Seaborn
* OpenCV
* Tkinter

# Machine Learning Algorithms
* K-Nearest Neighbors (KNN)
* Naive Bayes
* Decision Tree
* Support Vector Machine (SVM)

# Dataset
The project uses network traffic data collected and stored in CSV format. Data preprocessing and normalization are performed before training and testing the machine learning models.

# Project Workflow
1. Upload Network Traffic Dataset
2. Data Preprocessing
3. Feature Normalization
4. Model Training
5. Model Evaluation
6. Accuracy Comparison

# Results
| Algorithm     | Accuracy |
| ------------- | -------- |
| KNN           | 84%      |
| Decision Tree | 74%      |
| SVM           | 50%      |
| Naive Bayes   | 28%      |

### Best Performing Model

**K-Nearest Neighbors (KNN)** achieved the highest accuracy of **84%**.
